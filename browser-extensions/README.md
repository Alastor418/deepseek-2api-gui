# Browser Extensions — DeepSeek 2API Token Capture

Расширения для Chrome и Firefox. Перехватывают `Authorization` и `Cookie`
с `chat.deepseek.com` и автоматически отправляют их на локальный
`http://127.0.0.1:8080/gui/accounts`.

## Зачем

Headless-Playwright не может пройти hCaptcha при логине. Расширения решают
это: ты логинишься руками в обычном браузере один раз, а токен уходит
на сервер автоматически.

## Установка — Chrome / Chromium / Edge

1. Открой `chrome://extensions/`
2. Включи **Developer mode** (тумблер справа сверху)
3. Нажми **Load unpacked**
4. Выбери папку `browser-extensions/chrome/`
5. Расширение появится в списке. Закрепи его на панели (иконка пазла → 📌)

## Установка — Firefox

1. Открой `about:debugging#/runtime/this-firefox`
2. Нажми **Load Temporary Add-on…**
3. Выбери файл `browser-extensions/firefox/manifest.json`
4. Расширение загружено (до перезапуска Firefox)

**Если хочешь постоянную установку** — Firefox требует подписанное
расширение. Для личного использования хватает temporary add-on.

## Использование

1. Убедись, что сервер DeepSeek-2API запущен:
   `systemctl --user status deepseek-2api.service`
2. Открой `https://chat.deepseek.com/`
3. Залогинься (пройди капчу руками)
4. **Отправь любое сообщение** в чате
5. Расширение перехватит `Authorization` + `Cookie` и отправит на сервер
6. Проверь: `curl -s http://127.0.0.1:8080/gui/accounts | python3 -m json.tool`
   — должен появиться аккаунт с label `extension` (или `extension-ff`)

## Popup

Клик по иконке расширения открывает popup:

- **Статус** — когда последний раз отправляли, что ответил сервер
- **Адрес сервера** — можно поменять, если API на другом порту
- **Отправить токен сейчас** — повторная отправка последнего токена

## Ограничения

- Токен перехватывается **только когда ты делаешь запрос** к DeepSeek
  в браузере. Просто открыть чат недостаточно — надо отправить сообщение.
- Если ты давно не открывал DeepSeek в браузере, токен может протухнуть.
  Открой и отправь сообщение ещё раз.
- Расширение ничего никуда не логирует, кроме локального сервера и
  `browser.storage.local`. Никаких внешних запросов.
